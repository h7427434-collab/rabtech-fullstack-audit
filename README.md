# RabTech Full Stack Audit

## Project Architecture

This project uses a monorepo-style structure.

- `client/` — Frontend application and user interface.
- `server/` — Backend API routes, business logic, and server-side services.
- `docs/` — Accessibility audit reports and project documentation.
- `tests/` — Test plans and automated test cases.

## Local Setup

1. Clone the repository.
2. Install the required dependencies for the client and server.
3. Run the client and server applications locally.
4. Run the available tests.

## First Vertical Feature Slice

The first feature slice will connect a client-side interface to a server API endpoint and verify the complete request-response flow.
